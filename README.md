# DP-750 Prep — Practice Folder

Everything you need to study for the Microsoft Certified: Azure Databricks Data
Engineer Associate exam, in one place. Open `START_HERE.html` in a browser for a
navigable version of this same index — this file is the plain-text fallback.

## Folder map

- **docs/** — the 195-page study guide (PDF) plus a walkthrough of real GitHub
  projects worth studying.
- **datasets/** — ready-to-use sample data (customers, products, order events) for
  the capstone project. Real files, already generated — nothing to build first.
- **scripts/** — the order-data generator (make more sample data any time) and
  upload instructions for getting it all into Azure/Databricks.
- **capstone-project/** — the actual code from Part 5 of the guide (SQL, notebooks,
  a Lakeflow pipeline, and a deployable Databricks Asset Bundle), extracted into
  real files instead of PDF text.

## Suggested order

1. Open `docs/DP-750_Complete_Study_and_Interview_Guide.pdf` and start with Part 1.
2. When Part 1's environment setup is done, come back here and follow
   `scripts/upload_to_azure.md` to get the sample data into your workspace.
3. Work through Parts 2–4 of the guide.
4. When you reach Part 5, use `capstone-project/` as your working code instead of
   retyping everything from the PDF.
5. Read `docs/real_world_project_walkthrough.md` and compare a real public GitHub
   project against what you just built.
6. Parts 6–7: the practice question bank, interview prep, and your 30-day calendar.

Good luck — one attempt, and you've got a month and a real plan for it.
